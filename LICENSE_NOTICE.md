# Licensing status

No open-source license for the SASM-authored code is selected in this package.
Public visibility alone should not be described as an unrestricted open-source
license. The authors should select an appropriate license before advertising
the repository as licensed open-source software. Upstream licenses and dataset
attribution do not assign a license to the SASM-authored implementation.

The attached source models and derived numeric features are supplied with
provenance and the upstream notices in THIRD_PARTY_NOTICES.md. No raw ECG
signals or complete third-party backbone checkpoints are redistributed here.
