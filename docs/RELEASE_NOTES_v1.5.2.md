# SASM-ECG v1.5.2: adapter and micro-revision archive

This release preserves the v1.4.1 benchmark and adds the completed v1.5.1
shared-prior ECG/BCE adapter experiments and v1.5.2 micro-revision code/results.

- Archived four adapter implementations, development locks, episode metrics,
  paired statistics, role-swap, clinical/subgroup and single-core timing exports.
- Archived same-solver attribution, expanded development-grid sensitivity,
  calibration CIs, pathology DCA, interface forensics and Figure 5 source data.
- Added portable CSV-summary replay, historical runtime source snapshots,
  bootstrap/grid provenance and SHA-256 manifests.

Read `docs/V1_5_REPRODUCTION.md` for exact input and access boundaries. The
portable replay recomputes released aggregates; the archived research scripts
retain historical host paths and need complete upstream input caches for full
refitting. Raw waveforms, foundation checkpoints, Chapman development features
and complete new per-record prediction/model caches are not redistributed.

No new experiment, parameter search or historical-result modification was
performed by this release update. Manuscript editorial revisions are separate.
