# DCA and locked-threshold exports

These CSV and JSON files are result exports from the retrospective v1.3.0
supplementary analysis. They are provided for audit and table regeneration; the
repository does not claim that they constitute an end-to-end raw-waveform
rerun. The protocol and limitations are documented in
`docs/DCA_THRESHOLD_SCOPE.md` and `provenance/dca_threshold_protocol.json`.

`dca_summary.csv` and `dca_paired_effects.csv` contain support-seed summaries
for the five prespecified risk thresholds. `locked_threshold_summary.csv` and
`locked_threshold_paired_effects.csv` contain the two threshold rules and their
external performance. The complete class- and episode-level tables are attached
to the v1.3.0 GitHub Release because they are substantially larger than the
repository summaries.
